# VeyraOS — состояние разработки

Дата: 2026-10-29

## Цель проекта
Veyra OS 1.0 — минимальная Linux rescue-система для диагностики,
обслуживания и безопасного восстановления Linux-систем.

ВАЖНО: не собирать и не пересобирать ISO до готовности Veyra OS 1.0.
Не выполнять разрушающие операции с реальными дисками.

## Текущий компонент: Veyra Rescue
- Диагностика конфигурации fstab.
- Обнаружение загрузчика systemd-boot, EFI-файлов и UKI.
- Структурная проверка PE/COFF и секций UKI.
- Чтение метаданных UKI из .osrel.
- Разбор параметров ядра из .cmdline.
- Проверка PARTUUID относительно корневой файловой системы.
- Сверка rootfstype с фактическим типом файловой системы.
- Расчёт SHA-256 и проверка структуры таблицы Authenticode-сертификатов.

Диагностика не выполняла исправлений.

## Ограничения
- SHA-256 — отпечаток файла, а не доказательство подлинности.
- В проверенном UKI таблица Authenticode-сертификатов не обнаружена.
- Криптографическая проверка подписи, доверия к издателю и возможности
  загрузки пока не реализована.
- Наличие файлов загрузчика само по себе не доказывает исправность загрузки.
